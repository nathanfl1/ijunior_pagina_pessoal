Projetos

Gerenciador de livros com JavaFX!
Este projeto desenvolvido por mim e meus colegas durante a minha formação técnica no CEFET-MG é um sistema de gerenciamento de livros que utiliza a API do Google Books para buscar livros diversos, e permite ao usuário se cadastrar, adicionar esses livros à sua biblioteca, excluí-los caso necessário e avaliar os livros.
Simulador de jogos de tabuleiro!
Este projeto foi feito para um trabalho da disciplina de PDS2 e simula diversos jogos de tabuleiro como jogo da velha, damas, LigFour e Reversi. O sistema possui cadastro de usuários e mecânica de pontuação, sendo possível jogar com 2 jogadores.
Controle de pacientes com PostreSQL! Este projeto trata-se de uma aplicação CRUD com bancos de dados e Spring Boot. O Spring Boot se conecta ao banco de dados e fornece os dados para o front-end, dessa forma o usuário consegue cadastrar novos pacientes, visualizar relatórios, listar pacientes, etc.
